## Methodology

- Only public, non-fork, non-archived repositories are included.
- Commit and line-change statistics cover the full history of each default branch.
- PRs opened are attributed by creation date; merged PRs by merge date.
- Review counts are based on submitted GitHub pull-request reviews.
- Monthly metrics use UTC.
- Only the top 20 contributors and top 15 repositories are displayed.
- Lines added/deleted measure code churn, not engineering quality.
- Commits GitHub cannot associate with an account may be attributed to the Git author name.
